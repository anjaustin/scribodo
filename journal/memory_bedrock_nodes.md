# Diagnostic partitions

1. **Observed:** source selection and generation have different failure rates.
2. **Observed:** oracle generation fails without needing retrieval selection.
3. **Observed:** no accepted T1 output means T1 benefit is unmeasured.
4. **Unknown:** actual chat-template rendering of consecutive user roles.
5. **Unknown:** fresh single-fact capability with production runtime flags.
6. **Unknown:** JSON/citation and completion-budget contribution.
7. **Unknown:** slot reuse/recurrent-state contribution.
8. **Unknown:** reasoning-mode configuration and model-specific template behavior.

Dependencies: establish (4)/(5) before attributing (1)/(2) to capability. Separate
(6) from factual accuracy. Test (7) using repeated minimal baselines. Do not
interpret (3) as evidence against a functioning summary design.

Tensions: faithfully retaining the production protocol versus introducing
controlled diagnostic simplifications; explaining failures without tuning the
held-out test. Preserve production controls and label every ablation explicitly.
